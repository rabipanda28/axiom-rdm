Reference Data

Read Operations
GET /v1/reference-data/{dataSetId} Retrieve current reference data
Parameters
dataSetIdrequired
GET /v1/reference-data/{dataSetId}/versions Retrieve available versions
Returns all published versions available to the caller.
GET /v1/reference-data/{dataSetId}/audit Retrieve audit history
Returns maker/checker activity and published changes.
Change Operations
POST /v1/reference-data/{dataSetId}/changes Create a proposed change
Request body
{
  "reason": "Business date rollover",
  "data": {
    "businessDate": "2026-10-07"
  }
}
This API creates a change request. It does not directly update production reference data.
PUT /v1/reference-data/{dataSetId}/changes/{changeId} Update a proposed change
Only editable while the change is still in the maker stage.

Example response

{
  "dataSetId": "REF-PAYMENTS-DATE-CONTROL",
  "version": 42,
  "effectiveFrom": "2026-10-06T00:00:00Z",
  "data": {
    "businessDate": "2026-10-06"
  }
}
